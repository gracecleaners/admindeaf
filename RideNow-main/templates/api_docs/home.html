Quick Start

1

Get Your Access Token

Login to obtain your JWT access token:

# POST /api/accounts/auth/login/ { "username_or_email_or_phone": "your_email@example.com", "password": "your_password" } # Response: { "access": "eyJ0eXAiOiJKV1QiLCJhbGc...", "refresh": "eyJ0eXAiOiJKV1QiLCJhbGc..." }
2

Authorize in Swagger

Click the "Authorize" button and enter:

Bearer eyJ0eXAiOiJKV1QiLCJhbGc...
3

Start Testing!

Explore endpoints, test requests, and build your integration.
